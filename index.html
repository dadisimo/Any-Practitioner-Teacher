This interactive platform adapts to any subject. Drop study materials into the unformatted/ folder and they are automatically turned into quiz sections.

How It Works:

  1. Use each section’s Learn path (Basics → Advanced → Expert) plus free external tutorials
  2. Answer section questions (multiple choice, open text, or short code)
  3. Get a question wrong? Documentation opens immediately
  4. Study the material, then answer 3 follow-up questions correctly
  5. Fail 1 follow-up question? Back to documentation
  6. Pass the follow-up? Continue with the next quiz question
  7. Master all sections to complete your learning goal!
